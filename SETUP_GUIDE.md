# HAR Neural Network Health Monitoring - Setup & Execution Guide

## Complete End-to-End Implementation

### Architecture Overview

The app works in **two phases**:

#### **Phase 1: Offline Training (One-time)**

```
Raw UCI HAR Data (train.csv, test.csv, 561 features each)
           ↓
    [Preprocessing: Scale using MinMaxScaler to [-1, 1]]
           ↓
    [Train MLP: 561 → 256 → 128 → 64 → 6 (Softmax)]
           ↓
    Export Weights → public/model/weights.json
```

#### **Phase 2: Online Inference (Real-time in Browser)**

```
Simulated Sensor Readings (every 20ms, 6 values: acc_x,y,z + gyro_x,y,z)
           ↓
   Buffer Collection (accumulate 128 samples = 2.56 seconds)
           ↓
   Feature Extraction (28 time-domain + 6 correlation + 4 magnitude)
           ↓
   Load Pre-trained Weights from JSON
           ↓
   Forward Pass through MLP
           ↓
   Output: 6-class probabilities → Map to 2-class (ACTIVE/SEDENTARY)
           ↓
   Display Prediction on Dashboard
```

## The Live Classifier Component Explained

### How Real-Time Simulation Works

**Buffer Filling (Phase 1: Readings 1-128)**

```
Time  Reading  Buffer  Status
0ms     #1     1/128   Collecting...
20ms    #2     2/128   Collecting...
...
2540ms  #128   128/128  ✓ FULL → RUN INFERENCE
```

**One Prediction (Phase 2: Inference)**

```
2540ms: [128 readings filled]
  ↓
Extract 28+6+4=38 features (simplified, real = 561)
  ↓
Scale features using training params (crucial!)
  ↓
Forward pass: 38 → relu → ... → softmax(6)
  ↓
Get probabilities: [0.05, 0.02, 0.03, 0.10, 0.15, 0.65]
  ↓
Predict: "LAYING" (index 5, max prob)
  ↓
Binary: "SEDENTARY" (combine indices 3,4,5)
  ↓
Display on dashboard
```

**Window Slide (Phase 3: Setup for next)**

```
2560ms: [Keep readings 65-128, add new reading #129]
  Buffer state: 65/128
  ↓ Keep collecting to 128/128 again
3080ms: Back to 128/128 → RUN INFERENCE AGAIN
```

### Key Implementation Details

#### 1. **Sensor Buffer (Sliding Window)**


#### 2. **Feature Extraction**

```typescript

// Output: 561-feature vector (simplified in code, real UCI HAR features)

// Computed:
- Mean, Std Dev, Max, Min per axis (acc + gyro)
- Energy, SMA, Entropy per axis
- Correlations between axes
- Magnitude features
- Simplified frequency domain (FFT approximation)
- Padding to 561 dimensions
```

#### 3. **Data Scaling (CRITICAL)**

```typescript
// Must use TRAINING set parameters, NEVER test/live params!
// Scaling params saved in public/model/weights.json

scaled = ((raw - dataMin) / (dataMax - dataMin)) * 2 - 1;
// Result: all features now in [-1, 1] range
```

#### 4. **Value Alignment (Health-centric)**

```typescript

if (sedentaryProb >= 0.25)  // Threshold for safety
  → label = "SEDENTARY"     // Conservative: prioritize false positives
else
  → label = "ACTIVE" if activeProb > sedentaryProb else "SEDENTARY"
```

## Debugging & Troubleshooting

### Issue: "Failed to load pre-trained model"

**Cause:** weights.json doesn't exist  
**Fix:** Run `npm run train` first

### Issue: Low accuracy on live predictions

**Cause 1:** Model not trained (using random weights)  
**Cause 2:** Feature extraction mismatch between training & inference  
**Fix:** Compare feature extraction logic in Python (har_training.py) vs TypeScript (inference-engine.ts)

### Issue: Buffer never fills to 128

**Cause:** generateSensorSample() might have issues  
**Fix:** Check liv-classifier.tsx `collectSensorReading()` is being called every 20ms

### Issue: Weights load but predictions are random

**Cause:** Weights format mismatch or scaling parameters not loaded  
**Fix:** Verify `weights.json` has keys: `layer_0_weights`, `layer_0_biases`, `scaling_params`

## Advanced: Understanding the MLP Architecture

### Network Shape

```
Input (561)
    ↓ Dense + ReLU
  256 neurons (ReLU allows non-linearity)
    ↓ Dense + ReLU
  128 neurons
    ↓ Dense + ReLU
   64 neurons
    ↓ Dense + Softmax
    6 outputs (probability distribution over activities)
```

### Training Details

```
Loss Function:  Cross-entropy (multi-class)
Optimizer:      Adam (adaptive learning rate)
Learning Rate:  0.001
Batch Size:     32
Epochs:         100 (early stopping at epoch ~30-40)
Validation:     15% hold-out from training data
```

### Weight Initialization

```
Hidden layers:  He initialization (variance = 2/fan_in)
  → Prevents gradient vanishing/explosion in ReLU
Output layer:   Glorot initialization (variance = 2/(fan_in+fan_out))
  → Balanced for softmax
```
